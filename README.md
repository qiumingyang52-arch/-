# 化学助手网页版 / PWA

这是适合分享给他人使用的手机版版本。无需 Xcode 和 App Store；部署后把网址发给对方即可。iPhone 用 Safari 打开后，可点“分享 → 添加到主屏幕”，像普通 App 一样启动。计算和内置数据无需网络；首次打开网址需要网络，之后浏览器支持离线缓存。

## 最简单的发布方法

1. 将本文件夹上传到任意静态网站托管服务（例如 GitHub Pages、Netlify Drop 或 Vercel）。
2. 复制生成的网址发给对方。
3. 对方用 iPhone Safari 打开网址，选择“添加到主屏幕”。

建议使用 HTTPS；这样离线缓存和 PWA 安装功能才能完整工作。
